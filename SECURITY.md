# Security Policy

OpenKartLine is pre-alpha and has no stable release yet.

## Reporting a vulnerability

Do not publish an exploitable security issue in a public GitHub issue. Use GitHub's private vulnerability reporting for this repository when available. If that channel is unavailable, contact the repository owner privately through the address exposed on their GitHub profile.

Please include affected versions or commits, reproduction steps, impact, and any suggested mitigation. Maintainers should acknowledge a report within seven days and coordinate disclosure after a fix is available.

## Sensitive data

Telemetry can reveal locations, schedules, and driving behavior. OpenKartLine is local-first and should not upload data without explicit action. Contributors must use synthetic or intentionally redistributable fixtures and must never commit secrets or private telemetry.
