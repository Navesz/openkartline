# Support

OpenKartLine is an early open-source project maintained on a best-effort basis. There is no guaranteed response time or professional driving, engineering, or safety support.

## Where to ask

- Ask usage and modeling questions in [GitHub Discussions](https://github.com/Navesz/openkartline/discussions).
- Use the issue templates for reproducible bugs, scoped feature proposals, and research tasks.
- Follow [CONTRIBUTING.md](CONTRIBUTING.md) for local development and pull requests.
- Report exploitable vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

Before asking, search existing issues and discussions and try the latest release. Include the version, operating system, browser, sanitized logs, solver status, and the smallest synthetic project that reproduces the behavior.

## Data you must not post

Do not publish private telemetry, access tokens, precise personal-location history, licensed imagery, or files you do not have permission to redistribute. Replace sensitive input with a synthetic fixture whenever possible.

## Scope of advice

Simulation output is an estimate based on incomplete models and user-provided data. It is not a command to a vehicle, a substitute for instruction, or a guarantee that a maneuver is safe. Follow circuit rules, build speed progressively, and use a safety margin appropriate to conditions.
