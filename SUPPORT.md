# Support

OpenKartLine is pre-alpha and does not yet provide end-user simulation support.

- Use GitHub Discussions for design questions, modeling ideas, and usage help once Discussions is enabled.
- Use the issue templates for reproducible bugs and scoped feature proposals.
- Use the security process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Please do not post private telemetry, licensed track imagery, access tokens, or personal location data in public issues.
